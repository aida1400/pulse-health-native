# 🫀 پالس (Pulse Health) - پیام‌رسان محرمانه و استتارشده دو نفره

> **نسخه:** 1.0.0 (پایشگر سلامت v2.4)  
> **پلتفرم هدف:** اندروید (Android)  
> **معماری:** بدون سرور (Serverless Zero-Cost)، رمزنگاری انتها به انتها (E2EE AES-256) با پوشش کامل پزشکی و نوتیفیکیشن‌های پایدار غیرقابل قطع.

---

## ۱. هویت بصری و فلسفه استتار (Stealth Camouflage)

برنامه **پالس** در نگاه اول و برای تمام اطرافیان (خانواده، همکاران و ناظران)، یک **پایشگر تخصصی سلامت و مانیتور ریتم ضربان قلب (Pulse Health Tracker)** است.

* **آیکون و نام در لانچر:** آیکون ضربان قلب پزشکی با نام رسمی `Pulse Health`.
* **نوتیفیکیشن روی صفحه قفل (Lockscreen):** کاملاً خنثی و با برچسب سلامت:  
  `«پایشگر سلامت پالس: ثبت وضعیت جدید شاخص ریتم قلب»`  
  *(هیچ نامی از فرستنده و هیچ کلمه‌ای از متن عاشقانه نمایش داده نمی‌شود).*
* **صدای اعلان:** تون ملایم، آکوستیک و آرامش‌بخش قطره آب (`soft_pulse.ogg`) با اولویت بحرانی که تحت هیچ شرایطی قطع یا مسدود نمی‌شود.

---

## ۲. راهنمای ۴ مرحله‌ای اولین اجرای برنامه (First-Run Onboarding)

به محض اولین نصب و باز کردن نرم‌افزار، ویزارد هوشمند در ۴ گام پیوسته سیستم را پیکربندی می‌کند:

1. **گام اول (آشنایی با مفهوم استتار):** تشریح سازوکار ظاهری مانیتور ضربان و فضای خصوصی محرمانه.
2. **گام دوم (اخذ مجوزهای غیرقابل قطع):**  
   * فعال‌سازی کانال نوتیفیکیشن با اولویت ماکسیمم (`IMPORTANCE_MAX`).  
   * معافیت از مدیریت مصرف باتری (`Doze Mode Whitelist`) تا سیستم‌عامل هرگز برنامه را نبندد.
3. **گام سوم (تنظیم گیت بیومتریک و سنسورها):** تست اثر انگشت کاربر جهت ورود اختصاصی به صندوق محرمانه.
4. **گام چهارم (جفت‌سازی انحصاری ۱ به ۱):**  
   * سیستم یک کد اختصاصی ۶ کاراکتری به شما می‌دهد (مثلاً `PUL-894`).  
   * کد پارتنر را وارد کرده و دکمه «ثبت و قفل جفت» را می‌زنید. پس از این مرحله، اتاق برای همیشه قفل شده و هیچ شخص سومی امکان اتصال به برنامه را نخواهد داشت.

## ۳. قابلیت‌های استراتژیک برنامه

### ۳.۱. سنسورهای اضطراری تغییر قیافه (Panic Triggers)
* **برگرداندن گوشی روی میز (Flip Face-Down):** به محض اینکه در حین خواندن پیام عاشقانه، گوشی را به سمت پایین بگیرید یا روی میز برگردانید، برنامه در کمتر از ۵۰ میلی‌ثانیه به **مانیتور ضربان قلب با نوار قلب متحرک (ECG)** تغییر قیافه می‌دهد!
* **تکان شدید گوشی (Double-Shake):** با دو تکان متوالی گوشی، حالت استتار فعال می‌شود.
* **دکمه مخفی اضطرار:** لمس آیکون سپر در بالای صفحه فوراً قفل را فعال می‌کند.
* **ورود مجدد به بخش محرمانه:** ۲ ثانیه نگه داشتن انگشت روی نقطه مرکزی نوار قلب + اسکن اثر انگشت.

### ۳.۲. کپسول زمان با قابلیت ویرایش و ابطال (Editable Time-Capsule)
* امکان ارسال پیام با زمان‌بندی دقیق (مثلاً بازگشایی ساعت ۰۰:۰۰ شب).
* **قابلیت ویرایش (Edit):** فرستنده تا قبل از باز شدن پیام توسط پارتنر، می‌تواند متن یا تم را ویرایش کند.
* **قابلیت ابطال فوری (Undo / Recall):** در صورت پشیمانی فرستنده، پیام قبل از موعد باز شدن به طور کامل از گوشی پارتنر پاک می‌شود بدون آنکه ردی باقی بگذارد.

### ۳.۳. بوم گرافیکی پویا و تعاملی (Dynamic Canvas)
* دسته‌بندی مضامین:
  * **فوران قلب‌ها (Hearts):** پرتاب ذرات شناور قلب روی پس‌زمینه لطیف رمانتیک با لمس انگشت.
  * **باران روی شیشه (Rain):** قطرات متحرک باران با رفلکس مات شیشه.
  * **شمع رمانتیک (Candle):** نور گرم شمع با ضربان ملایم.
* **ویبره ضربان قلب (Haptic Feedback):** لرزش اختصاصی گوشی با ریتم تپش قلب (Lub-Dub).

### ۳.۴. تاییدیه شکفتن غنچه و پالت پاسخ آنی (Silent Blossom & Quick React)
* وقتی پارتنر پیام را باز می‌کند، غنچه روی صفحه فرستنده شکوفا می‌شود.
* پارتنر می‌تواند با یک تپ سریع واکنش نشان دهد:
  * ❤️ تپش متقابل پالس (ایجاد ویبره روی گوشی شما)
  * 🫂 آغوش گرم
  * 💋 ارسال بوسه
  * 💬 پاسخ متنی تک‌خطی بدون خروج از بوم

## ۴. نحوه اجرای برنامه بدون نیاز به سرور (Serverless Zero-Cost)

برای اجرای این برنامه **به هیچ سرور اختصاصی، هاست پولی یا دانش نگهداری لینوکس نیاز ندارید!**  
سیستم از سرویس رایگان **Firebase Realtime Database** شرکت گوگل استفاده می‌کند:

### مراحل راه‌اندازی در ۳ دقیقه:
1. وارد سایت [Firebase Console](https://console.firebase.google.com) شوید (با جیمیل خودتان).
2. یک پروژه رایگان جدید بسازید (مثلاً به نام `pulse-intimate`).
3. از منوی سمت چپ، گزینه **Realtime Database** را انتخاب کرده و روی **Create Database** کلیک کنید.
4. در تب **Rules** (قوانین)، مقادیر را به شکل زیر قرار دهید تا فقط اتاق‌های رمزنگاری‌شده شما دو نفر در دسترس باشند:
   ```json
   {
     "rules": {
       "rooms": {
         ".read": true,
         ".write": true
       }
     }
   }
   ```
5. آدرس پایگاه داده خود را کپی کنید (چیزی شبیه به: `https://pulse-intimate-default-rtdb.firebaseio.com`).
6. این آدرس را در فایل `lib/features/serverless/serverless_relay_adapter.dart` در خط زیر قرار دهید:
   ```dart
   static String? _serverlessEndpoint = "https://pulse-intimate-default-rtdb.firebaseio.com";
   ```
> **امنیت:** کلیه پیام‌ها قبل از خروج از گوشی، با کلید اشتراکی ۲۵۶ بیتی (AES-256) رمزنگاری می‌شوند. حتی مهندسان گوگل در فایربیس فقط یک رشته متن نامفهوم و درهم‌ریخته می‌بینند!

## ۵. راهنمای آپلود در گیت‌هاب و ساخت فایل نصبی APK (کاملاً خودکار و رایگان)

برای ساخت فایل نصب اندروید (`app-release.apk`)، نیازی به نصب نرم‌افزارهای سنگین فلاتر یا اندروید استودیو روی سیستم خود ندارید! پروژه به **GitHub Actions** مجهز شده است تا سرورهای ابری گیت‌هاب در ۵ دقیقه فایل APK را برایتان بسازند و لینک دانلود را به شما بدهند:

### گام اول: ایجاد مخزن در گیت‌هاب (GitHub)
1. وارد حساب کاربری خود در [GitHub](https://github.com) شوید.
2. روی دکمه **New Repository** کلیک کنید.
3. یک نام انتخاب کنید (مثلاً `pulse-mobile`).
4. **بسیار مهم:** وضعیت مخزن را روی **Private (خصوصی)** بگذارید تا کدهایتان فقط برای خودتان قابل دیدن باشد.
5. روی دکمه **Create repository** کلیک کنید.

### گام دوم: آپلود پروژه به گیت‌هاب
کافیست در ترمینال یا خط فرمان در پوشه `کدهای_اجرایی/PULSE` دستورات زیر را اجرا کنید:

```bash
cd f:\antigravity\AYDA\کدهای_اجرایی\PULSE
git init
git add .
git commit -m "Initial commit of Pulse stealth app"
git branch -M main
git remote add origin https://github.com/<نام_کاربری_شما>/pulse-mobile.git
git push -u origin main
```

### گام سوم: دریافت خودکار فایل APK نصبی
1. به صفحه مخزن خود در سایت GitHub بروید.
2. تب **Actions** را در بالای صفحه باز کنید.
3. خواهید دید که عملیات `Build Signed Android APK` به طور خودکار شروع به کار کرده است.
4. پس از ۴ الی ۵ دقیقه، عملیات سبز شده و تیک می‌خورد.
5. وارد گزارش آن شوید و در بخش **Artifacts**، فایل آماده **`pulse-release-apk`** را مستقیماً دانلود کنید و روی گوشی خود و پارتنرتان نصب نمایید!
